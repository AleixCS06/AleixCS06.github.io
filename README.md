# 🌐 Aleix Claramunt – Personal Portfolio Website

This is the official personal portfolio website of **Aleix Claramunt Soler**, designed to showcase education, work experience, technical skills, and featured projects in a clean and professional format.

## 📌 About the Project

This website serves as a digital résumé and personal brand platform for Aleix. It provides a concise overview of his background as a junior software developer, including academic history, technical competencies, internship experiences, and selected portfolio highlights.

Rather than simply listing information, the goal is to offer a dynamic and accessible way for potential employers, collaborators, or interested parties to learn about Aleix’s work and professional identity.

## 💡 Concept & Design

The website is built upon a **Bootstrap-based portfolio template** sourced from the open web. The base template was customized and adapted to better align with Aleix's personal style and content structure.

While the design is template-based, the project involved:

- Structuring and adapting HTML/CSS content
- Organizing professional data in a clear and readable format
- Ensuring mobile responsiveness and clean navigation
- Custom tweaks to improve UI/UX flow and branding

## ⚙️ Technologies Used

- **HTML5** – markup structure
- **CSS3** – for visual customization
- **Bootstrap** – front-end framework for responsive design
- **GitHub Pages** – hosting and deployment

## 🎯 Purpose

This portfolio is meant to:

- Provide a public, shareable overview of Aleix's professional profile
- Support job applications and networking opportunities
- Serve as an evolving project that can grow with new content and features over time
